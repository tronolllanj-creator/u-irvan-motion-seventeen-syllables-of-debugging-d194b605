This repository contains a program that writes one original haiku about debugging (three lines, 5-7-5 syllables) to entry.txt. Here is the shipped haiku:

```
Bug hides from my eyes
steps aside when I look up
window shows my face
```

## Run it
```sh
python3 main.py
```
